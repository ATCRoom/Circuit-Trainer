# GIF and pictures to record

**Rules for all of them**

- Tool: ScreenToGif, "Recorder" mode. Frame rate 15 fps, record only the Circuit Trainer window (or the part that matters).
- Length 5–15 s, loop. Area 1280 x 720 (whole window), 800 x 600 (detail) or the size of a single window. File size under 4 MB (ScreenToGif: Save as → Gif, lower the quality).
- No real names, no Windows user name in a path or title bar. Use callsigns like SIM / IBLA / PONY / VIPER.
- Move the mouse slowly; stop one second at the end of each action.
- Save in `docs/tutorials/gifs/` with the exact name below.
- **Same aerodrome and runway for all of them** (a well-known one, map loaded), instructor window maximised, panels in the place you like but **not over the runway**, dark panels (the light ones only in the pictures).
- The pictures (PNG) go in `docs/images/` with the exact name; same rules.
- **Priority:** if there is little time, record the ones marked ★ first; the others can wait.
